# MCP-сервер PIXEL PLANNER

Даёт нейросети доступ к вашему аккаунту: читать день, задачи, привычки, финансы и питание, добавлять записи.
Действия описаны в `src/assistant/tools.ts` обычным JSON Schema и не зависят от MCP: те же действия потом получат
бот с нейронкой и микрофон в приложении.

## Подключение
1. В приложении: личный кабинет → «Ключи доступа» → «Создать ключ». Скопируйте ключ `ppk_…`.
2. Соберите сервер: `npm run build:mcp` (получится `mcp/dist/pixel-planner-mcp.mjs`).
3. Подключите к клиенту:
   - **Claude Code:** `claude mcp add pixel-planner -e PP_API_KEY=ppk_… -- node /полный/путь/mcp/dist/pixel-planner-mcp.mjs`
   - **Claude Desktop, Cursor, Gemini CLI и другие с MCP по stdio:** команда `node`, аргумент — путь к файлу, переменная окружения `PP_API_KEY`.

Если сервер не открывается напрямую (VPN), запросы сами идут через посредника на Cloudflare.

## Действия
`get_day`, `list_backlog`, `add_task`, `complete_task`, `mark_habit`, `add_transaction`, `finance_overview`, `find_food`, `log_food`.

## Что ключ может и чего не может
Может читать и добавлять записи (`/api/sync`) и узнать, чей он (`/api/auth/me`). Не может стирать данные аккаунта,
менять пароль, удалять аккаунт, управлять ключами и смотреть админку. Отзывается в кабинете одной кнопкой.

## ChatGPT и сайт claude.ai
Им нужен удалённый MCP по HTTPS с входом через OAuth. Это следующий шаг: те же действия, другой способ подключения.
